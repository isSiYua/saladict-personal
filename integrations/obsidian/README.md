# Saladict Selection Translator for Obsidian

在 Markdown 编辑模式或阅读模式中用鼠标划选文字，松开鼠标后会在选区旁自动打开 Saladict 浮层。

## 功能

- 无需快捷键的自动划词翻译
- 对照本项目 Edge 版 Saladict 的紧凑工具栏和分词典卡片
- 可拖动、缩放、固定的浮动查词窗口
- 可从工具栏切换为真正的独立窗口；回到编辑或阅读视图继续划词时，独立窗口会保持打开并刷新结果，也可直接输入查词
- 固定小窗口后，继续划词只刷新词典内容，不再改变窗口位置或因空选区关闭
- 面板宽度、最大高度、字号、主题、默认固定、自动隐藏、自动发音、词典启用与顺序均可配置
- 可直接导入 Edge Saladict 导出的 `.saladict` 设置，并导出 Edge 可再次导入的同格式文件；浏览器专属字段会原样保留
- 句子与段落默认使用 Google、彩云、有道、百度多源翻译；Google 首张展开，其他来源像 Edge 一样后台加载并保持折叠
- 单词继续使用 Google 翻译，以及有道、必应、牛津、剑桥、柯林斯、在线词源词典多来源结果
- 划词后立即自动朗读；支持原生音频或系统语音
- 独立的重新朗读与暂停/继续按钮
- 长词典默认半展开并显示渐变展开箭头；句子与段落的原文、译文不做预览截断
- 默认取消人为弹出延迟；同一会话内的重复查询与并发查询会复用缓存
- 上一个/下一个查词记录、设置、收藏与收藏夹入口
- 直接复用本项目内置的词典图标和各词典预览高度
- 收藏词条和收藏管理弹窗
- 点击浮层外部或按 `Esc` 关闭
- 新选词取消旧请求，避免旧结果覆盖新结果

## 安装

将打包产物中的 `saladict-selection-translator` 文件夹复制到 Vault 的 `.obsidian/plugins/`，然后在社区插件设置中启用。
